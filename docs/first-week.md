- **A 先修首件再复用流程。** 修正侧缝外扩、领口开洞、包臀下摆和袖口差异，补尺寸口径。灰模与贴图版使用同一几何；第二件 POLO 单独制作翻领和门襟。以新目录版本交同一人物、两件独立 GLB、manifest 和哈希，C 核对正侧背贴合。
- **B 使用现有测试包开工。** B02 已有真机旋转、换衣和缺资产提示的记录。B03 在同一换衣入口加入目录下载、大小和 SHA-256 校验、完整版本缓存，以及推荐编号、理由和模式。验浅色、深色、无匹配、断网复网，补测过期目录、旧响应、损坏文件和换衣失败。
