# 头部贴图流水线（扫描路线）

更新于 2026-11-25。本文件记录头部扫描重建、UV 展开、贴图烘焙与交付验收，以及可复现的运行清单。个人采集、模型权重和渲染结果保留在本地工作区 `outputs/`，仓库只保留可公开的通用工具与匿名化指标。

## 2026-11-25 突破：V9 纯本地开源 AI 辅助前景解耦重建管线

针对此前头部重建“正脸歪斜、一侧眼窝高低畸变、后脑勺 `270°` 竖直缝与平滑泥块感”两大问题，本轮完成量化定位并基于纯本地开源模型落地了 **V9 前景解耦重建管线**（已封装为通用零硬编码 CLI [`reconstruction/reconstruct_head_v9.py`](../reconstruction/reconstruct_head_v9.py)）：

1. **量化根因**：在静态背景（门框、家具）锁定的 COLMAP 坐标系下，长视频（113 秒）拍摄中的活体微晃与微偏头导致正脸双瞳跨帧重投影漂移达 **12–18 px**，直接剪切五官与眼窝几何；同时背光帧清晰度跌至拉普拉斯方差 `28.1–61.2`（正常侧脸 `275.4`），叠加 `facing^16` 极端权重造成 `270°` 断崖死线。
2. **纯本地 AI 方法栈（不依赖外部闭源云端生成）**：
   - **前景 SfM（`SuperPoint + LightGlue` + `SegFormer`）**：利用 `mattmdjaga/segformer_b2_clothes` 屏蔽静态背景后在纯前景区域提取并全对匹配，以 85/85 全帧注册生成 `4,142` 个纯前景 3D 点（平均重投影误差 **`1.4267 px`**）。
   - **人体表面法线大模型（`Meta Sapiens2-Normal-0.4B`）**：bfloat16 本地推理并自动校准至 OpenCV 相机坐标系（与 `Depth-Anything-V2` 面部余弦相似度 **`0.8697`**），替代深度差分伪法线以约束对称眼窝曲率与发体流向。
   - **2DGS + 头部解耦可微 6-DoF 位姿联合微调**：仅在 `Face | Hair` 区域计算光度与法线/深度损失反向更新每帧刚体残差 `(Δω_i, Δt_i)`（隔离下身衣物晃动），将正面双瞳重投影漂移压低至均值 **`2.62 px`**（中位位姿微调 `0.586°`），前景渲染 PSNR 达 **`25.95 dB`**（`72,533` 个纯前景高斯）。
   - **无断崖烘焙与安全护栏**：对 `24` 帧逆光后脑勺帧在 `Lab` 空间做温和暗部拉回与 `CLAHE`，改用 `facing^5` + 限幅锐度权重并叠加切线空间 `Sapiens2` 法线贴图（2048×2048），导出清洁 `.glb`（`8.49 MB`、`100,000` 面、`num_boundary_loops = 2`）并自动剥离 Filament 禁用材质扩展。
3. **如实记录的当前局限**：
   - 相比旧版，正面五官水平对称度与 `270°` 断崖线得到明显改善；但当源视频存在背窗强逆光时，非生成式方案仍受原始像素高频信息上限约束，后脑勺近景发丝质感偏柔顺，须通过端侧采集引导避开强逆光。

## 烘焙

- 每个 texel 的归属由图集光栅结果决定，唯一所有者取「最深者」，并列取面序小者；因此不存在后写面覆盖先写面。
- 遮挡用 Embree 精确深度，一次全分辨率 z-buffer，深度即相机坐标系 z。
- 扩边只动岛外 texel：安全区距离取 `min(8 px, 岛间距/2)`，之外用最近所有者颜色铺满整图集，避免 mipmap 采到背景。
- 只用训练相机；颜色在线性空间做多视角加权平均，再转回 sRGB。

## 交付验收

用标准 glTF 加载路径验收，不再用自写光栅器判断效果：本地 three.js r186 的 GLTFLoader → WebGL2（无头 Chrome，ANGLE/D3D11）→ 画布回读 PNG，六视角与照片同相机同分辨率。

- GLB 顶点属性为 `POSITION`、`NORMAL`、`TEXCOORD_0`；上一版缺法向，查看器只能平面着色。
- 采样器显式写 `CLAMP_TO_EDGE` 与 `LINEAR_MIPMAP_LINEAR`，避免扩边颜色被绕回对侧岛。
- 内嵌 PNG 解码后的像素与磁盘贴图完全一致；字节哈希可能不同，因为导出工具会重新编码 PNG，两项都记在核对文件里。
- 同一套照明下，贴图版比顶点色版亮 5–14%；相对照片的亮度比在 0.64–1.18。

顶点色按 glTF 约定属于线性空间，而网格里的顶点色本身已是线性值，因此导出时不再做一次 sRGB→linear 转换；做了会让顶点色版整体偏暗约三成，对照就不公平。

输出为六视角各自两版（1434×648）、两张耳部微距（900×900）和 48 帧旋转预览。

## 耳朵近景取景

上一轮的近景用图像比例常数裁剪，拍到的多是头发。本轮改为几何取景：拍摄轨道轴定向上方向，横截面宽度剖面定头部范围，用邻域拉普拉斯算子的凹陷度找耳甲腔，窗口取耳片投影包围盒的 1.8 倍并对齐重心。

| 检查项 | 数值 |
| --- | --- |
| 耳片投影占窗口（线性） | 左 0.54、右 0.56 |
| 耳片是否全部落在窗口内 | 是 |
| 两侧耳心横向坐标之和 | −0.047（头半宽的 5.8%） |
| 两侧耳心高度差 | 0.044（头高的 11.3%） |
| 最佳视角下耳片可见比例 | 1.0 |

这套数字只证明取景框住了检测到的耳部区域，不代替人眼对画面观感的判断。

## 运行清单与复用

- 每次运行写一份不可变清单，另有累计索引；顶层清单只指向最新运行并保留全量列表，只有跑完全部阶段的运行才更新「最新完整运行」。
- 复用需要同时满足：输入、参数、代码与依赖版本的指纹一致，且上次记录的产物逐个重算 SHA-256 一致。任一不符即重算，并写明拒绝原因。
- 烘焙指纹覆盖 84 张训练照片、84 张掩膜、COLMAP 相机文件、数据集参数、展示视角文件、配置与脚本，以及相关库版本。
- 阶段参数写入参数文件由子命令读取，子命令把生效参数回显进产物统计，运行时比对，避免「指纹里有、实际没用」。
- 减面产物由该阶段显式返回文件路径，不再扫目录取最新文件。

确定性：重跑减面得到的网格与上一轮哈希相同；重跑展开得到的 UV 与光栅文件逐字节相同。

低成本失效检查在独立输出目录、降档参数下逐项验证：首次全流程全部执行、原样再跑全部复用、改参数只重算相关阶段、篡改产物被拒并重算且结果逐字节一致、改配置只影响以配置为输入的阶段、单阶段运行不抹掉完整记录。26 项全部通过。

## 需要如实记录的限制

- 头顶存在几何缺口，属于融合与网格问题，贴图流程无法弥补。
- 五官细节偏软，受网格分辨率与扫描表面质量限制。
- 9.3% 的 texel 无照片命中，仍用顶点色兜底，集中在耳后、下颌底和颈根等遮挡区。
- 耳部近景的观感需人工确认：几何定位与对称性通过，但该区域受头发遮挡和网格质量限制。
- 无头浏览器的截图来自画布回读，不是窗口截图；渲染环境为单台机器的集显，其他显卡上的观感需另测。
- 本轮只改贴图流程，没有用涂色或模糊处理掩盖几何缺陷。
