## 1｜三条口径（先定死，否则数字不可比）

1. **同一条件**：同一操作者、同一台机器、同一份输入；每项跑 3 次取**中位数**。
2. **耗时分三段**：模板准备 / 人工操作 / 总耗时。等待类（训练、导出、排队）单独列，不混进人工操作。
3. **终点定义**：以「导出 GLB 且通过交付门禁 `export_glb_guard.py check`」为终点，不以"看起来能跑"为终点。

### 2.1 手工侧网格规模（本轮实测，非引用）

### 2.2 手工侧缺陷基线（静态几何预检，11-19）

- 躯干 / 袖 / 下摆：无穿入，最小间隙 **7.12 mm**。
- 领圈滚边：`top-001` 最大穿入 **≤ 3.7 mm**、`top-002` **≤ 2.3 mm**，集中在 `y ≈ 1.53 m` 滚边区。
- 三方案等比缩放仿真证明改胸宽消不掉领圈穿入（[仿真记录](../../local-data/handoff/T02-三方案几何仿真-1121.md)）。
- 真机四视角判定：两件**通过**（A 侧 11/24 签收，C 会签中），领圈按拍板口径登记遗留项。

## 3｜已知缺口（如实登记，不补编）

- `03b` 两件的**建模 / 精修耗时没有逐段计时**，只有"什么时候交了什么"的时间戳，无法反推人工小时数。因此 §2 的手工列耗时行不填数字，只写「未逐段计时」。
- 结论写法上要区分：**扫描辅助的完整分段计时只有 `top-003` 一路有**，所以「省了多少时间」只能对可比的环节做定性比较，不做百分比外推。
- 若队长手上有手工阶段的估算口径，补进来时必须注明是估算而非实测。

## 4｜填写规则

1. 每个数字后面标来源：文件路径 / 命令 / 截图编号，三者之一。
2. 未测就写「未测」，不要用「约」「大概」。
3. 扇区数与 `up_roll_median_deg` 只能来自手机界面当场记录，PC 端算不出来。
4. 影像、`.blend`、`.glb` 走内部渠道；本表只放指标与计数。
