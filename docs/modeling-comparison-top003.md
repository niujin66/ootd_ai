## 1｜三条口径（先定死，否则数字不可比）

1. **同一条件**：同一操作者、同一台机器、同一份输入；每项跑 3 次取**中位数**。
2. **耗时分三段**：模板准备 / 人工操作 / 总耗时。等待类（训练、导出、排队）单独列，不混进人工操作。
3. **终点定义**：以「导出 GLB 且通过交付门禁 `export_glb_guard.py check`」为终点，不以"看起来能跑"为终点。

### 2.2 手工侧缺陷基线（静态几何预检，11-19）

- 躯干 / 袖 / 下摆：无穿入，最小间隙 **7.12 mm**。
- 领圈滚边：`top-001` 最大穿入 **≤ 3.7 mm**、`top-002` **≤ 2.3 mm**，集中在 `y ≈ 1.53 m` 滚边区。
- 三方案等比缩放仿真证明改胸宽消不掉领圈穿入（依据 `T02-三方案几何仿真-1121.md`，该文件在本地 `local-data/handoff/` 物料目录、未入公开仓库）。
- 真机四视角判定：两件**通过**（A 侧 11/24 签收，C 会签中），领圈按拍板口径登记遗留项。

### 2.3 扫描侧实测（`top-003` V9.1，11/26 夜）

采集：手机两段式引导（12 扇区 **100%** 覆盖）；重建：2DGS → TSDF → 烘焙，前景 PSNR **32.439 dB**（队长登记值）。

| 项 | 实测 |
|---|---|
| GLB 体积 / 顶点 / 三角面 | 7.91 MB / 60,947 / 100,000 |

## 3｜已知缺口（如实登记，不补编）

- `03b` 两件的**建模 / 精修耗时没有逐段计时**，只有"什么时候交了什么"的时间戳，无法反推人工小时数。因此 §2 的手工列耗时行不填数字，只写「未逐段计时」。
- 结论写法上要区分：**扫描辅助的完整分段计时只有 `top-003` 一路有**，所以「省了多少时间」只能对可比的环节做定性比较，不做百分比外推。
- 若队长手上有手工阶段的估算口径，补进来时必须注明是估算而非实测。
- **COLMAP `sparse/0` 交叉核验未做**：本机没有 `colmap` 可执行文件与 `pycolmap`（见 `_work` 环境记录），且本件 2DGS 由队长侧重跑，A 侧拿不到 `sparse/0`。表里只登记端侧 12/12 扇区，不拿头部消融的 8/12 → 9/12 冒充本件结果。
- **2DGS 初模耗时未计时**：同上，属队长侧；表里给的是同机头部消融的参考值，已明确标注不是本件。
- **真机四视角结论未出**：静态预检只能给几何间隙，不能替代 C 的真机判定；腋下 0.08 mm 这条需要 C 在四视角里确认是否可见。
- 若 `person-001_v2` 的头部与躯干接缝后续调整，肩/领区数字要重跑，本节口径不变。
