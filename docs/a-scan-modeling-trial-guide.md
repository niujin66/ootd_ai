# A 岗实操指南：用团队「采集引导 → 2DGS 转网格 → Blender 精修」方法制作新上衣（`top-003`）

> 适用对象：**A（`@VowVole`）**　｜　冲刺周期：**2026-11-23 至 11-30**　｜　关联任务：[`#13`](https://github.com/niujin66/ootd_ai/issues/13)

## 1. 为什么要做这次实操

当前 03b 两件衣服（白色短袖 `top-001`、蓝色翻领 POLO `top-002`）主要依赖传统手工建模与贴图流程。过去一周团队已经跑通「**手机端两段式实时采集引导 → 确定性+AI质检 → COLMAP / 2DGS 深度融合转网格 → Blender 精修与适配**」的新管线（详见[服装高斯转网格记录](garment-gaussian-mesh.md)和[采集引导设计](capture-guidance-design.md)）。

本轮请 A 用这套新方法独立完整走通**第 3 件真实上衣 `top-003`**（优先选择与现有短袖、POLO 版型不同的款式，如连帽卫衣、夹克或长袖衬衫），目标有两项：
1. **交付可用资产**：产出贴合固定 B 版身体（`pose-001`）、通过 `export_glb_guard.py` 校验的 `top-003.glb`，与 `03b` 合并为候选包 `fixture-face-04`。
2. **产出比赛对照数据**：记录《手工建模 vs 扫描辅助建模》的耗时与精度对比表，直接写入参赛《技术研究报告》与《作品创新性分析报告》。

## 2. 四步操作链（11/24 – 11/28）

### 第 1 步：用新版 Android 端「3D 采集引导」拍摄（11/24–25）

1. **安装或构建最新端侧包**：基于 `main@16d9a50` 及之后的提交安装测试版 APK（或向队长/B 获取最新安装包）。
2. **开拍准备页填写**：
   - 打开首页底部的 **「3D 采集引导」**；
   - 选择 **「衣物 3D 采集」**，样本编号填 `top-003`；
   - 在衣物旁/人台脚边平放已知尺寸参考物（如标准 A4 纸或卷尺），并打开 **「地上/旁边已放标尺或 A4 纸」** 开关；
   - 如需体验 AI 补拍建议且暂无共享服务器，可展开准备页底部的 **「开发者调试」**，填入共享测试后端地址或个人 DeepSeek API Key（Key 仅保存在手机本地 `SharedPreferences`）。
3. **一镜到底两段式拍摄**：
   - **阶段 1（远景定骨架，10–15 秒）**：站在 1.2–1.5 m 处，将整件衣物放入屏幕中央**虚线安全框**内（占比 35%–55%，四边留出空隙），保持手机水平（水平仪居中），按方向指示缓慢匀速绕目标走一圈，点亮右上角 **12 个 30° 扇区**。
   - **阶段 2（一镜慢推近补细节，5–10 秒）**：外圈达标后**不要点停止**，点击右下角 **「进入第 2 步：慢推近」**，固定衣物纹丝不动，镜头缓慢凑近至 30–50 cm 拍清领口、肩线、袖口及面料纹理，最后点击完成。
   - 录完的视频会自动保存至手机相册 `Movies/OOTD-Capture/`。

---

### 第 2 步：用离线质检工具硬核把关（11/25）

将手机相册 `Movies/OOTD-Capture/` 中刚录好的 MP4 拷贝到电脑（注意不要提交原始录像到 Git 仓库），在 `d:\软创文件\ootd_ai` 根目录执行：

```powershell
# 1) 纯本地确定性指标检查（或加上 --call-guide 查看补拍指南）
.\server\.venv\Scripts\python.exe server/tools/analyze_capture.py `
  --input <你的本地MP4视频路径> `
  --target-type garment `
  --subject-label top-003 `
  --has-scale-reference true `
  --call-guide
```

若本机已启动或已接入服务端（`--server-url http://<服务地址>:8000 --token <令牌>`），也可同时带上参数调用远端 `/v1/capture/guide`。

**送入重建前的及格线**（未达标不硬跑重建，按输出 `steps` 立即补拍/重拍）：
- 12 个 30° 扇区全覆盖（无 `>= 90°` 背面大空缺）；
- 相机翻滚中位偏差 `up_roll_median_deg <= 20°`；
- 四边留白 `min_margin_px` 均 `>= 40 px`（避免领口/下摆/袖口裁切）；
- 清晰度中位数 `sharpness_p50 >= 35.0`、相邻帧连续度 `orbit_continuity_min >= 0.35`。

---

### 第 3 步：2DGS 重建出初模（11/26，按显卡条件分流防卡死）

为防止环境配置挤占冲刺时间，按 A 手头设备条件直接分流：

- **分支 A（本机有 NVIDIA CUDA 显卡）**：
  参考[服装高斯转网格记录](garment-gaussian-mesh.md)既有流程执行：`COLMAP` 相机对齐（如用均匀抽帧 + 加密转角采样）→ 语义掩膜提取（注意清除裤腿/背景误收，参考第 33 轮经验）→ `2DGS` 训练与深度融合导出三角网格（避免分位数过严截平帽顶/肩线，参考第 43 轮经验）。
- **分支 B（本机无 CUDA 显卡或环境配置超过 2 小时未通）**：
  **立即止损**：于 **11/25 晚前**将已通过第 2 步质检的 MP4 与尺度参考照片通过团队内部渠道传给队长（`@niujin66`）。由队长在本地 GPU 环境跑出 `2DGS` 原始三角网格（OBJ/GLB）及基准相机对照图回传给 A，A 直接进入第 4 步精修。

---

### 第 4 步：Blender 精修、B 版身体适配与交付门禁（11/27–28）

1. **对齐固定身体基准**：
   - 将扫描出来的 `top-003` 网格导入 Blender，参照 A04 确定的尺度（结合拍照时的 A4 纸/卷尺标定尺寸与实衣平铺胸宽 `W_flat`）对齐固定 B 版身体（`pose-001`、米制 Y 向上、正面朝 `+Z`、脚底中心原点）。
2. **按实测经验做针对性精修**（不用全手工从零拉点，重点修扫描网格的 4 类常见瑕疵）：
   - 清理背景/下装粘连产生的长条杂面与悬空碎片（参考第 33 轮）；
   - 修补袖口、领口与下摆内侧遮挡区，确保过渡带与衣身**共用边界顶点/共用边**、减少单侧裂边（参考第 42 / 45 轮）；
   - 在 B 版身体上检查正、侧、背面与斜侧贴合，消除明显穿模；
   - 烘焙或整理移动端兼容的贴图材质。
3. **跑导出门禁并交接给 C 验收**：
   导出时严禁携带会触发 Android Filament 崩溃的 `KHR_materials_specular` / `KHR_materials_sheen` 扩展。交付前务必运行：

   ```powershell
   # 检查并剥离禁用扩展
   python server/tools/export_glb_guard.py check <输出目录或top-003.glb>
   # 若 check 报存在禁用扩展，执行剥离后再次 check：
   python server/tools/export_glb_guard.py strip <源目录> <干净输出目录> top-003.glb
   ```

   随后结合 `03b`（`person-001.glb`、`top-001_v2.glb`、`top-002_v1.glb`）生成 3 衣候选包 `fixture-face-04`（含更新后的 `manifest.json`、三方 SHA-256 交接清单、Blender 源工程索引与四视角基准图），于 **11/28 晚**通过内部渠道交 C（`@uniquebugle-stack`）校验导入与真机核对。
