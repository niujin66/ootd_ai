# 服装高斯转网格实验记录

更新于 2026 年 11 月 25 日。单条卫衣环绕视频已生成可回读的离线网格。第 33 轮是清理背景后的对照底版，第 42 轮固定了实验袖口，第 45 轮是最新帽缘候选。手机试衣继续使用独立实衣包 `fixture-face-03b`。

## 2026-11-25 评估结论：头部 V9 方法向衣物管线的迁移取舍

结合头部 V9 纯本地开源 AI 管线的实测表现，对**衣物建模方向**明确以下更新策略：

| V9 核心模块 | 衣物场景适用性 | 建议做法 |
| --- | --- | --- |
| **`SuperPoint + LightGlue` 前景 SfM** | **✅ 强烈建议迁入** | 纯色卫衣/哑光针织衫在暗部常导致 SIFT 特征点不足；屏蔽背景后用 LightGlue 可提升暗部配准与闭环稳定性，减少背景杂面。 |
| **`SegFormer` 语义前景与内缩边缘过滤** | **✅ 强烈建议迁入** | 替代容易混入裤腿/地砖的启发式分割（对应第 33/34 轮痛点），用严格掩码与边缘离群过滤避免背景色沾边。 |
| **`facing^5` 柔和融合 + 逆光暗部拉回** | **✅ 强烈建议迁入** | 消除强侧逆光与高次幂权重导致的衣身明暗断崖线，并在导出前强制走 `export_glb_guard.py` 剥离禁用扩展。 |
| **可微 6-DoF 位姿微调** | **⚠️ 分场景按需开启** | 若衣服套在静止人台/衣架上拍摄，开启微幅 `1°` 级位姿精修即可补偿手持微抖；若真人边穿边晃产生布料**非刚体形变**，刚体 6-DoF 无法解决布料错位，仍需靠采集端静止。 |
| **`Sapiens2-Normal-0.4B` 法线先验** | **⚠️ 不作衣物几何主力** | Sapiens2 面向整个人体外观先验，在**袖口内衬、领口厚度、下摆封口与精确平铺尺寸拟合**上**不能替代**第 37–45 轮验证的「2DGS 初模 + Blender 共用边封口与 B 版身体校准」流程。 |

**结论与落地进展（2026-11-25 晚）**：上述三项高收益模块（`SegFormer` 严格零外扩衣物掩码 + 空衣架 `GrabCut` 回退、`SuperPoint + LightGlue` + `SIMPLE_RADIAL` 去畸变、`Lab` 逆光暗部拉回 + `facing^5` 无缝 2048 UV 烘焙 + `export_glb_guard.py` 扩展剥离）已封装入通用无硬编码脚本 [`reconstruction/reconstruct_garment_v9.py`](../reconstruction/reconstruct_garment_v9.py)。实测优化细节如下：

- **长款衣物兼类与暗孔闭合**：将 `upper` 从纯标签 `4 (Upper-clothes)` 扩展为 `(4, 7)`，防止大版型卫衣侧背面被 `SegFormer` 归为 `7 (Dress)` 时侧视轮廓截断；增加 `max_hole_ratio=0.25` 闭合内孔填充以修补袋鼠兜阴影误判（`0` 帧触发外扩或 `GrabCut` 回退，76 清晰帧面积占比分布 `[0.3592, 0.5386, 0.8183]`，裤腿/拖鞋/背景零混入）。
- **去黑边伪角点与两级 SfM 回退**：`stage_sfm` 直接在原图提取 `SuperPoint` 关键点（消除黑底裁剪边缘产生的滑动轮廓伪角点），先用内缩衣物内部关键点跑 Pass 1，若注册率不足 80%（例如纯色卫衣侧面纹理少，Pass 1 注册 `42/76`）则自动回退全图无遮罩 `SuperPoint+LightGlue` Pass 2，导出时再切回严格零外扩衣物掩码。实拍卫衣 76 帧隔离冒烟测试实现 **`76/76 (100%)` 全注册**、`6851` 个三维点、平均重投影误差 **`1.3132 px`**、平均轨迹长 `4.521`。
- `top-003` 冲刺主线继续使用 [A 岗实操指南](a-scan-modeling-trial-guide.md)（本机有 CUDA 显卡时可在第 3 步直接使用 `reconstruct_garment_v9.py` 生成初模），随后按第 37–45 轮经验做 Blender 封口与身体校准确保 11/28 交付。

## 第 36 轮复核

- 两个参与外侧补面构建的原片视角，局部网格轮廓与工作遮罩的 IoU 分别为 0.697 → 0.886、0.682 → 0.856。这组数值衡量与工作遮罩的一致性，独立留出视角仍需核对。
- 导出文件用顶点色标记来源。灰色是原网格，蓝色包含由深度恢复的外侧及拟合腕缘，橙色是根据另一只袖口估计的内侧，约占总网格面积 0.9%。
- 在 GLB 索引中，底版、外侧补面、腕缘与内侧带仍是独立面组。外侧补面与底版有 22 个不同坐标位置重合，接缝面组未共用边。报告中 3.7° 来自袖口邻域内已经相邻的面，接缝两侧尚待测量。
- 以拟合袖口平面为基准，沿轴线从外侧 0.12 模型单位采样至内侧 0.25 模型单位。中心及较内侧样本通过，近边缘 8 条射线中有 3 条撞到外侧补面。新斜侧近景同时显示尖片和悬空碎片。

## 第 36 轮提出的复测条件

先在这一处裁掉重叠面和碎片，给原袖筒和补面建立共用边，复验真实接缝两侧的法线过渡和腕口通畅。用同一相机比较修补前后，再选一张未参与构建且看得清袖口的原片做独立对照。帽缘、下摆、贴图和手机换装适配分别验收，进度登记在[验收记录](acceptance-record.md)。

实验由本地扫描环境运行。个人影像、可识别模型与派生预览按[团队规范](team-standards.md)在团队内部留存。移动端采用已交接的独立衣物包验收，本实验尚未替换该包。
