# OOTD AI · 衣序

衣序面向日常穿搭，在 Android 上展示本人的三维人物，根据场合和偏好推荐已有衣物，点击后切换独立三维上衣。

## 2026-11-09 进度

| 部分 | 当前结果 |
| --- | --- |
| 本人人物 | 照片重建已运行。B 版体型获得本人确认，作为衣物适配基准 |
| 面部外观 | 本人近照投影着色已生成。头发和眼镜几何、侧面外观仍待完善 |
| 电脑换衣 | 同一人物和两件合成测试短袖可旋转、切换，切换保持视角 |
| 后端 | 资产校验、导入、四接口及推荐适配器已实现。测试执行 73 项，72 项通过、1 项跳过 |
| Android | B01 首页经 B 运行、C 登记验收。手机三维加载与换衣待完成 |
| 真实衣物 | C 总表记录 A01 采集验收通过，队长本机尚未收到素材。当前先补齐交接 |
| AI 推荐 | mock 联调通过，真实模型调用与效果待验证 |

当前内部联调包为 `fixture-face-01`，固定 `pose-001`，含 `person-001.glb`、`top-001.glb`、`top-002.glb` 和 `manifest.json`。它用于手机加载测试；两件真实衣物还需要制作与验收。
