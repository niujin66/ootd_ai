# OOTD AI · 衣序（暂名）

衣序是一款面向日常穿搭的 Android 试衣助手。它从用户本人的照片或视频还原三维人物，根据场合推荐已有衣物，并让用户在同一个人物上换装、旋转查看效果。

项目处于启动阶段，首周先验证人物重建和换装，随后接入 AI 推荐。

## 首版范围

| 能力 | 验收标准 |
| --- | --- |
| 本人三维重建 | 从一名自愿参与者的照片或视频生成三维人物，保留输入与模型输出的对应记录，核对脸部和体形。重建可在电脑端提前计算。 |
| 三维换装 | 固定姿势与下装，在同一人物上替换两件同类短袖的独立三维资产。在 Android 上旋转检查正面、侧面和背面，记录穿模或残留。 |
| AI 推荐 | 输入一个场合和偏好，推荐已有且可试穿的衣物。点击推荐结果后加载对应的三维衣物。没有合适选项时说明原因。 |

首版集中在一名参与者、两件同类短袖和一个场合，优先跑通推荐到换装的流程。
