# 消息与记录模板

## 1. 交接五段式（A/B 每天用）

```text
任务编号和负责人
当前状态和对应版本
可检查的结果或报错
运行或复现步骤
下一步、接收人和检查时间
```

## 2. 每日总表更新（发在总表 Issue 评论）

```markdown
## 2026-11-09 更新
- A01：待办 → 待验收（清单已到）
- B01：待办 → 进行中（分支已建）
- Q01：未测 → 通过（10/10）
- 下次检查：2026-11-10 18:00
- 需决定：无
```

## 3. 决策项（发队长，≤3 条）

```text
【待决定】<一句话>（影响 Q0x）
问题：<事实 + 数字>
选项：A … / B …
建议：<选哪个，为什么一句>
影响：<不定会怎样>
请：<谁> <何时> 前定 <什么>
```

示例：

```text
【待决定】Q03 穿模判定阈值（影响 Q03）
问题：文档只写「影响演示」，无阈值，D7 可能结论不一致
选项：A 静置 3 秒内可见即失败 / B 仅遮挡面部或大面积才算
建议：A，可复现、可截图
影响：不定则 Q03 无法给出一致结论，返工
请：队长 2026-11-12 18:00 前定
```

## 4. 无决策项

```text
今日无待决定项。进度见总表 Issue。
```

## 5. 失败退回（发 A 或 B）

```text
Q0x 未通过
版本/提交：
复现步骤：
期望：
实际：
首个报错/截图：
请补/修：<具体项>
下次检查：<日期 时点>
```

## 6. 升级（卡住超过 1 天）

```text
【卡住】<任务编号> 已停在 <现象> <时长>
已尝试：<1–2 条>
需要：<谁> 提供 <什么>
不解决的后果：<影响哪项验收 / 哪个日期>
```
